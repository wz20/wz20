## 👋 关于花卷

我是 **花卷**，一名专注于 **Java 后端、AI Agent 与 Vibe Coding** 的创作者。

我喜欢把抽象的 AI 概念，做成真正能运行、能演示、能被看见的产品、工具与视觉作品。

- 🔭 正在探索：AI Agent、LangChain / LangGraph、MCP、AI 工作流
- 🧩 擅长方向：Java、Spring Boot、微服务、AI 应用工程
- 🎨 持续创作：提示词工具、视觉模板、自动化视频与创意项目
- 🐱 实验室吉祥物：花卷，一只参与产品命名与灵感生产的小猫
