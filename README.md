## 你好，我是花卷

**Java 后端 · AI Agent · 创意编程**

把 AI 想法，做成看得见、能运行的作品。这里记录我围绕智能体、知识管理和视觉表达的开源实践。

- **让 AI 参与实际工作**：把知识整理、记忆维护和审阅流程做成可复用的 Agent 工具。
- **让软件更有趣**：把本地知识库做成 3D 小屋，探索桌宠与交互体验。
- **让技术更好理解**：用动画、插画和视频呈现机制，把创作流程沉淀为 Skill。
